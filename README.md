# Portfólio — Murilo Gabriel

Portfólio estático, responsivo e sem dependências de runtime. Projetos, tecnologias e links ficam centralizados em `scripts/data.js`.

## Desenvolvimento local

```bash
python3 -m http.server 4173
```

Acesse `http://localhost:4173`.

## Publicação

O diretório pode ser publicado diretamente na Vercel como site estático, sem comando de build.
